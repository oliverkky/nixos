# Shortcuts

The main point is to be able to move through this environment either with keyboard only or mouse only.

## System shortcuts

`Main + F` Puts active window on fullscreen.
`Main + Escape` Opens system menu.

## Aplications

`Main + Space` Opens Rofi. Inspired by Spotlight.
`Main + B` Opens Brave Browser.
`Main + O` Opens Obsidian.
`Main + Z` Opens Zed.
`Ctrl + Shift + Esc` Opens Mission Center. Inspired by Task Manager.
`Main + Return` Opens terminal.
